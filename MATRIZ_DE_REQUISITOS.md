# Matriz de requisitos · AgroEdge IA

La implementación funcional de referencia es `d045786`. La distribución académica conserva el modelo `exposure-tflm-2c4870d61d3f` y añade el firmware compilable, la protección de bytes del fixture NOAA y rutas de verificación. Los datos y resultados archivados se ubican mediante el [índice de evidencias](evidencias/README.md). La entrega de código es independiente del informe y del video.
